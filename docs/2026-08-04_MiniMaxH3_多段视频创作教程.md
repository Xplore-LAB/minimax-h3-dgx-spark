# MiniMax H3 多段视频创作实战教程

> **版本**：2026-08-04 实战验证（spark-44a8 全流程跑通）
> **成果**：5 段拼接 25 秒《雨夜追逃》→ 8 段拼接 40 秒《集结》

## 2. HTTP API 批量提交（不用开浏览器）

核心节点链（带音频三件套）：

```
UNETLoader(FL2VA) → MiniMaxH3SigmaShift(shift_video=12, shift_audio=3)
CLIPLoader(Qwen3VL, type=minimax) ──┐
VAELoader(视频VAE fp16) ─────────────┼→ MiniMaxH3ImageToVideo → KSampler(20步,cfg1.0)
VAELoader(音频VAE fp32) ─────────────┘        ↑                ↓
EmptyMiniMaxH3LatentAV(w,h,length)          negative        VAEDecode → CreateVideo → SaveVideo
                                                              VAEDecodeAudio → SaveAudio
```

提交函数（Python，可直接复用）：

```python
def submit(prefix, seed, prompt, first_frame=None):
    wf = {
     "1": {"class_type": "UNETLoader", "inputs": {"unet_name": "minimax_h3_fl2va_pruned_int8_convrot.safetensors", "weight_dtype": "default"}},
     "2": {"class_type": "CLIPLoader", "inputs": {"clip_name": "qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors", "type": "minimax"}},
     "3": {"class_type": "VAELoader", "inputs": {"vae_name": "minimax_h3_video_vae_fp16.safetensors"}},
     "4": {"class_type": "VAELoader", "inputs": {"vae_name": "minimax_h3_audio_vae_fp32.safetensors"}},
     "5": {"class_type": "EmptyMiniMaxH3LatentAV", "inputs": {"width": 864, "height": 480, "length": 124, "batch_size": 1}},
     "6": {"class_type": "MiniMaxH3SigmaShift", "inputs": {"model": ["1", 0], "shift_video": 12.0, "shift_audio": 3.0}},
     "7": {"class_type": "MiniMaxH3ImageToVideo", "inputs": {"clip": ["2", 0], "vae": ["3", 0], "prompt": prompt, "width": 864, "height": 480, "length": 124}},
     "8": {"class_type": "CLIPTextEncode", "inputs": {"clip": ["2", 0], "text": "text, subtitles, logos, watermarks, animation, cartoon rendering, overly-CG look, blurry, low quality, deformed"}},
     "9": {"class_type": "KSampler", "inputs": {"model": ["6", 0], "positive": ["7", 0], "negative": ["8", 0], "latent_image": ["7", 1], "seed": seed, "steps": 20, "cfg": 1.0, "sampler_name": "euler", "scheduler": "simple", "denoise": 1.0}},
     "10": {"class_type": "VAEDecode", "inputs": {"samples": ["9", 0], "vae": ["3", 0]}},
     "11": {"class_type": "VAEDecodeAudio", "inputs": {"samples": ["9", 0], "vae": ["4", 0]}},
     "12": {"class_type": "CreateVideo", "inputs": {"images": ["10", 0], "fps": 24.0}},
     "13": {"class_type": "SaveVideo", "inputs": {"video": ["12", 0], "filename_prefix": prefix, "format": "auto", "codec": "auto"}},
     "14": {"class_type": "SaveAudio", "inputs": {"audio": ["11", 0], "filename_prefix": "audio/" + prefix}}
    }
    if first_frame:
        wf["15"] = {"class_type": "LoadImage", "inputs": {"image": first_frame}}
        wf["7"]["inputs"]["first_frame"] = ["15", 0]
    req = urllib.request.Request("http://127.0.0.1:8188/prompt",
        data=json.dumps({"prompt": wf, "client_id": "x"}).encode(),
        headers={"Content-Type": "application/json"})
    return json.load(urllib.request.urlopen(req, timeout=20))
```

关键参数：
- `length`: 124≈5s，362≈15s（上限 15s）
- 批量：循环调用 submit() 即自动排队串行（队列机制，不会并行 OOM）
- 查状态：`curl http://127.0.0.1:8188/history/<prompt_id>` 或 `/queue`

## 3. 音画合成 + 音量归一化（必须做）

H3 音频 VAE 输出的音效**电平极低**（峰值约 -34dB，人耳听不见），必须 loudnorm：

```bash
ffmpeg -y -i video.mp4 -i audio/xxx.flac \
  -af "loudnorm=I=-16:TP=-1.5:LRA=11" -c:v copy -c:a aac -shortest \
  final.mp4
# 归一化后峰值约 -3~-5 dB（正常听感）
```

批量处理循环：

```bash
for seg in seg1 seg2 seg3; do
  ffmpeg -y -i ${seg}_00001_.mp4 -i audio/${seg}_00001.flac \
    -af "loudnorm=I=-16:TP=-1.5:LRA=11" -c:v copy -c:a aac -shortest \
    ${seg}_final.mp4 2>/dev/null
done
```

## 4. 多段拼接成大片

所有片段统一规格（864×480、24fps、aac）后，用 concat demuxer 无损拼接：

```bash
: > concat.txt
for seg in seg1 seg2 seg3 seg4 seg5; do
  echo "file '/path/${seg}_final.mp4'" >> concat.txt
done
ffmpeg -y -f concat -safe 0 -i concat.txt -c copy full_video.mp4
```

GIF 预览（发微信用）：

```bash
ffmpeg -y -i full_video.mp4 \
  -vf "fps=8,scale=540:-1:flags=lanczos,split[s0][s1];[s0]palettegen[p];[s1][p]paletteuse" \
  -loop 0 preview.gif
```

## 5. 剧情连贯性优化（重点经验）

**问题**：独立生成的每段，角色长相、场景、镜头各自为政，拼接后跳变明显。

**三重解法**：

| 手段 | 做法 | 效果 |
|---|---|---|
| **长段化** | 8×5s → 3 段（15s+15s+10s） | 接缝 7→2，段内剧情连续 |
| **尾帧接首帧** | 段 N 完成后抽最后一帧，作为段 N+1 的 first_frame | 场景/色调/角色位置直接延续 |
| **角色定妆统一** | 每个角色在提示词里固定外观描述（颜色/服装/特征） | 同一角色跨段长得一致 |

**尾帧抽取**：

```bash
ffmpeg -y -sseof -0.1 -i segN_final.mp4 -frames:v 1 segN_lastframe.png
```

**提示词模板**（统一 look 前缀 + 固定角色 + 分镜 + 音效）：

```text
[统一look] Epic blockbuster superhero team-up movie, cinematic photorealistic live-action,
IMAX scale, sweeping anamorphic lens, dramatic volumetric lighting, rich color grading,
film grain, powerful natural movement.

[固定角色] HERO_A = "a powerful armored hero in sleek dark-gold metal armor with glowing
golden energy lines"; HERO_B = "an agile hero in deep-red tactical armor with a blazing
golden energy shield"; HERO_C = "a flying hero in blue-and-silver suit with a long
flowing dark cape"

[连续剧情] Continuation: ...（描述上一段结尾如何衔接到本段）

[音效] Audio: ...（每段独立设计，配乐走向连贯）

[禁止] No text, subtitles, logos or watermarks, no animation or cartoon rendering,
keep photorealistic live-action texture.
```

## 7. 完整生产流水线

```text
1. 设计剧情线（分幕分镜）→ 每段写提示词（统一 look + 固定角色）
2. 循环 submit() 提交全部段（自动排队）
3. 每段完成：抽尾帧 → 作为下段 first_frame（依赖链，串行提交）
4. 全部完成：批量 loudnorm 合成 → concat 拼接 → GIF
5. 验收：音画同步、角色一致、场景连续、无跳变
```

> **进阶**：batch_size>1 可同提示词多 seed 批量出片（同内容多版本选优）；
> 图生视频（first_frame）可做"照片→动态"；R2V 需另下载 ref2va 模型。
