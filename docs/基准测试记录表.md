## 3. 测试规则

1. 每次测试前停止其他大模型容器。
2. 使用同一提示词、Seed、采样参数。
3. 第一次运行视为冷启动，另行标记。
4. 至少记录一次热启动。
5. “成功”要求输出可播放、画面非黑、有音频、服务未退出。
6. 只改变一个因素：分辨率、时长或内存参数。
7. 出现 OOM 后先采集诊断，不立即尝试更大任务。
